ICSA-26-244-03 / CVE-2026-9637

ControlLogix CIP Message Input Validation Flaw (Denial of Service)

CVSS Score: 7.5 High (v3.1) / 8.7 High (v4.0) • Impact: Complete Loss of Controller Availability (C:N / I:N / A:H).

A malformed CIP packet with an invalid payload length header triggers a Major Nonrecoverable Fault (MNRF) in Logix 5580 and 5380 controllers. The controller halts all motion and requires a physical on-site power cycle. This is an availability bug, fundamentally separate from project-file logic tampering.

Vulnerability Mechanics

The controller's firmware CIP parser failed to properly validate the length field of incoming encapsulation packets. An attacker sends a crafted frame with length greater than allocated buffer space, causing a memory dereference fault.
